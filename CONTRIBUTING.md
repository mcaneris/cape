# Contributing to Cape

Thank you for your interest in contributing to Cape!

## Development Setup

1. Clone the repository
2. Install Rust (if not already installed): https://rustup.rs/
3. Run tests: `cargo test`
4. Run examples: `cargo run --example <example_name>`

## Submitting Changes

1. Fork the repository
2. Create a feature branch: `git checkout -b feature-name`
3. Make your changes
4. Run tests: `cargo test`
5. Run clippy: `cargo clippy`
6. Run fmt: `cargo +nightly fmt`
7. Commit your changes with a clear message
8. Push to your fork and submit a pull request

## Code Style

- Follow standard Rust formatting (`cargo +nightly fmt`)
- Address all clippy warnings (`cargo clippy`)
- Write tests for new functionality
- Update documentation as needed

## Questions?

Feel free to open an issue for discussion before starting work on significant changes.
